## Задача 2. Без null
### Текст задачи
Создайте сущность Хранилище, которая обладает следующими характеристиками:
- Может хранить один произвольный объект в один момент времени.
- Хранилище неизменяемо. Объект кладется в Хранилище при его создании. В качестве объекта может быть сохранено также и значение null.
- Хранилище может вернуть ссылку на Объект. Если вместо объекта хранится null, необходимо вернуть какое-либо альтернативное значение.
- Метод получения значения должен работать с тем типом данных, который был указан во время создания объекта.

Выполните следующие задания:
- Создайте Хранилище чисел, положите туда значение null. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должно быть число 0.
- Создайте Хранилище чисел, положите туда значение 99. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должно быть число -1.
- Создайте Хранилище строк, положите туда значение null. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должна быть строка "default".
- Создайте Хранилище строк, положите туда значение "hello". Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должна быть строка "hello world".

### Алгоритм решения
1. Создать обобщенный класс `Storage<T>`, помеченный модификатором `final` для предотвращения наследования.
2. Объявить неизменяемое поле `private final T item`, которое инициализируется единственным конструктором `public Storage(T item)`.
3. Реализовать метод `public T getOrDefault(T alternative)`, возвращающий `item`, если он отличен от `null`, либо `alternative`, если в поле хранится `null`.
4. Реализовать метод `public T getItem()` для прямого доступа к полю и переопределить метод `toString()`.
5. В демонстрационном методе протестировать все 4 сценария из условия (числа с `null` и `99`, строки с `null` и `"hello"`) с соответствующими альтернативными значениями. Организовать ввод пользовательских значений с клавиатуры с проверкой корректности.

## Задача 5. Обобщенная линия
### Текст задачи
Измените сущность Линия из задачи 2.6.3, таким образом, чтобы:
- При создании её объекта можно было точно указать тип точки, на которой расположена линия: двухмерная или трехмерная (из задачи 2.3.5).
- Методы получения и установки значения Точки также могли работать с типом указанным при создании объекта.
- Граница стирания не может быть хуже двумерной точки.

Создайте и выведите на экран произвольную линию в трехмерном пространстве.

### Алгоритм решения
1. Описать базовый класс `Point2D` с вещественными координатами `x`, `y`, конструктором, геттерами, сеттерами и методом `toString()`.
2. Создать класс `Point3D`, наследующийся от `Point2D`, добавив координату `z`, соответствующий конструктор через `super(x, y)` и расширенный метод `toString()`.
3. Создать обобщенный класс `Line<T extends Point2D>`, где ограничение `<T extends Point2D>` гарантирует, что тип точек линии не может быть хуже двумерной точки (верхняя граница стирания типов).
4. В классе `Line` объявить приватные поля `T start` и `T end`, конструктор для их инициализации, геттеры и сеттеры с типом `T`, а также переопределить `toString()`.
5. В методе `main` запросить у пользователя ввод координат трёхмерных точек через клавиатуру с валидацией, создать объект `Line<Point3D>` и вывести его строковое представление.

# Задание 2. Параметризации. Маски типов и их ограничения

## Задача 1. Сдвинуть линию
### Текст задачи
Создайте метод, принимающий Линию из задачи 3.1.5 (с любой допустимой параметризацией) сдвигающей точку начала на 10 единиц по оси Х. Например, если Х был 5, то должен стать 15, если Х был -7, то должен стать -17.

### Алгоритм решения
1. Создать сервисный класс `LineService` со статическим методом `shiftLineStart(Line<?> line)`.
2. Использовать нетипизированную маску (wildcard) `Line<?>`, что разрешает передачу линии с любой корректной параметризацией (`Point2D`, `Point3D` и т.д.).
3. Получить ссылку на точку начала через `Point2D start = line.getStart();`, пользуясь тем, что граница стирания типа — `Point2D`.
4. Считать текущую координату `x = start.getX()`.
5. Проверить знак координаты:
   - Если `x >= 0`, установить новое значение `start.setX(x + 10)`.
   - Если `x < 0`, установить новое значение `start.setX(x - 10)`.
6. Продемонстрировать работу метода на созданной трёхмерной линии, выводя состояние до и после сдвига.

# Задание 3. Обобщенные методы. Автовывод типа

## Задача 1. Функция
### Текст задачи
Разработайте такой метод, который будет принимать список значений типа Т, и объект имеющий единственный метод apply. Данный метод надо применить к каждому элементу списка, и вернуть новый список значений типа Р, при этом типы Т и Р могут совпадать, а могут не совпадать.

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", а получите список чисел, где каждое число соответствует длине каждой строки.
2. Передайте в метод список со значениями: 1, -3, 7, а получите список в котором все отрицательные числа стали положительными, а положительные остались без изменений.
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только максимальные значения каждого из исходных массивов.

### Алгоритм решения
1. Объявить обобщенный интерфейс `Transformer<T, P>` с методом `P apply(T value)`.
2. Реализовать статический универсальный метод `public static <T, P> List<P> transform(List<T> source, Transformer<T, P> transformer)`:
   - Создать пустой список `List<P> result = new ArrayList<>()`.
   - В цикле пройти по элементам `source`, для каждого вызвать `transformer.apply(item)` и добавить результат в `result`.
   - Вернуть полученный список.
3. Разработать три класса, реализующих интерфейс:
   - `StringLengthTransformer` (`Transformer<String, Integer>`): возвращает `value.length()`.
   - `AbsoluteValueTransformer` (`Transformer<Integer, Integer>`): возвращает `Math.abs(value)`.
   - `MaxArrayTransformer` (`Transformer<int[], Integer>`): находит максимальный элемент в массиве (при пустом массиве возвращает 0).
4. Продемонстрировать вызов метода на контрольных наборах данных.

## Задача 2. Фильтр
### Текст задачи
Разработайте такой метод, который будет принимать список значений типа Т и объект имеющий единственный метод test (принимает Т и возвращает boolean). Верните новый список типа Т, из которого удалены все значения не прошедшие проверку условием.

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и отфильтруйте все строки имеющие менее трех символов.
2. Передайте в метод список со значениями: 1, -3, 7, и отфильтруйте все положительные элементы.
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только те массивы, в которых нет ни одного положительного элемента.

### Алгоритм решения
1. Объявить обобщенный интерфейс `Condition<T>` с методом `boolean test(T value)`.
2. Реализовать обобщенный метод `public static <T> List<T> filter(List<T> source, Condition<T> condition)`:
   - Создать пустой список `List<T> result = new ArrayList<>()`.
   - В цикле обойти входную коллекцию, проверяя условие `condition.test(item)`.
   - При истинном результате сохранить элемент в `result`.
   - Вернуть отфильтрованный список.
3. Реализовать три класса условий:
   - `MinLengthCondition` (`Condition<String>`): проверяет `value.length() >= 3`.
   - `NegativeOrZeroCondition` (`Condition<Integer>`): проверяет `value <= 0` (исключает строго положительные).
   - `NoPositiveElementsCondition` (`Condition<int[]>`): проверяет отсутствие элементов `> 0` во всем массиве.
4. Продемонстрировать фильтрацию на контрольных данных.

## Задача 3. Сокращение
### Текст задачи
Разработайте такой метод, который будет принимать список значений типа Т и способ с помощью которого список значений можно свести к одному значению типа Т, которое и возвращается из метода.

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и сформируйте одну большую строку, которая состоит из всех строк исходного списка.
2. Передайте в метод список со значениями: 1, -3, 7, и верните сумму всех значений исходного списка.
3. Имеется список, состоящий из списков целых чисел, получите общее количество элементов во всех списках. Подсказка: решить задачу можно в одно действие или последовательно использовать методы из 3.3.1 и 3.3.3.

Далее необходимо изменить разработанный метод таким образом, чтобы данный метод гарантированно не возвращал null и не выбрасывал ошибок в том случае, если исходный список пуст.

### Алгоритм решения
1. Создать обобщенный интерфейс `Combiner<T>` с методом `T combine(T left, T right)`.
2. Реализовать универсальный метод свертки с нейтральным элементом: `public static <T> T reduce(List<T> source, Combiner<T> combiner, T identity)`:
   - Инициализировать аккумулятор `T result = identity`.
   - Проверить `source != null`. Обойти элементы списка в цикле, накапливая значение: `result = combiner.combine(result, item)`.
   - Вернуть `result`. При пустом списке возвращается ненулевой `identity`, что гарантирует отсутствие ошибок и возврата `null`.
3. Создать классы объединения:
   - `StringConcatCombiner` (`Combiner<String>`): конкатенация строк (`left + right`).
   - `IntegerSumCombiner` (`Combiner<Integer>`): сложение чисел (`left + right`).
4. Для подсчета элементов списка списков применить композицию:
   - Преобразовать `List<List<Integer>>` в `List<Integer>` (размеры вложенных списков) с помощью метода `transform` из задачи 3.1.
   - Свернуть полученный список размеров с помощью `reduce` и `IntegerSumCombiner`.
5. Протестировать поведение метода на пустом списке.

## Задача 4. Коллекционирование
### Текст задачи
Разработайте такой метод, который будет возвращать коллекцию типа Р со значениями типа Т.
Данный метод будет принимать:
1. Список исходных значений
2. Способ создания результирующей коллекции
3. Способ передачи значений исходного списка в результирующую коллекцию.

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: 1, -3, 7, и верните их разбитыми на два подсписка, в одном из которых будут только положительные числа, а в другом только отрицательные.
2. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", "qw" и верните их разбитыми на подсписки таким образом, чтобы в любом подсписке были строки только одинаковой длины.
3. Передайте в метод список со значениями: "qwerty", "asdfg", "qwerty", "qw" и верните набор такого вида, который не может содержать одинаковые объекты.

### Алгоритм решения
1. Создать два интерфейса:
   - `ResultFactory<R>` с методом `R create()` для инкапсуляции создания структуры данных.
   - `ResultWriter<R, T>` с методом `void add(R result, T value)` для инкапсуляции логики наполнения структуры.
2. Реализовать метод `public static <T, R> R collect(List<T> source, ResultFactory<R> factory, ResultWriter<R, T> writer)`:
   - Создать пустой контейнер: `R result = factory.create()`.
   - В цикле обойти исходные элементы `source`, передавая каждый в `writer.add(result, item)`.
   - Вернуть заполненный контейнер `result`.
3. Реализовать классы фабрик и писателей для каждого примера:
   - **Пример 1 (разделение по знаку):** фабрика создает `Map<String, List<Integer>>` с ключами `"positive"` и `"negative"`, писатель раскладывает числа по условию `>= 0` и `< 0`.
   - **Пример 2 (группировка по длине):** фабрика создает `Map<Integer, List<String>>`, писатель по длине `value.length()` создает или пополняет соответствующий вложенный список.
   - **Пример 3 (уникальный набор):** фабрика создает `LinkedHashSet<T>`, писатель добавляет элементы через стандартный `.add()`, устраняя дубликаты.
4. Протестировать работу коллектора на тестовых наборах из условия.
